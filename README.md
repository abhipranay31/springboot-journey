# Spring Boot Learning Journey

My 30-day journey to learning Java, SQL, REST APIs, and Spring Boot through practical projects.

## Day 1 — Java Foundations

### Concepts learned
- Classes and objects
- Fields and methods
- Object references
- Multiple variables referring to the same object
- Reference reassignment
- Java compilation and execution

### Practical work
- Created and ran a `Student` class.
- Created multiple student objects with different data.
- Traced reference assignments and predicted program output.

### Key learning
Assigning one object reference to another does not create a new object. Changes to the shared object's fields are visible through both references. Reassigning a reference changes which object that variable refers to.
